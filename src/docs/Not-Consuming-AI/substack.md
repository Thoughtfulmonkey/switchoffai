# Substack

[Substack](https://substack.com/) is a social media platform that supports longer essays and written works.

## Scan for AI text

Substack partnered with [Pangram](https://textguard.ai/) to add AI detection. You can select the ellipsis icon on a Substack post, and then select **Scan for AI Text**. However, Pangram uses AI to analyse the text, and also sells Text Humanizer services (which use AI to modify AI-generated text so that it isn't detectable as AI by other AI detection services).

Because the feature uses AI, and is provided by an AI company that's selling both the poison and the antidote, I don't recommend that anyone uses it. Instead, only subscribe to people who you trust
